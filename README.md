# proyectos-dev

Tres proyectos de front-end (HTML, CSS y JavaScript sin frameworks):

1. `01-landing-refrigeracion/`: landing para servicio técnico. Servicios desde un array, zonas de atención, formulario que arma un mensaje de WhatsApp.
2. `02-catalogo-productos/`: catálogo con búsqueda, filtro por categoría y orden por precio.
3. `03-formulario-turnos/`: formulario de reserva con validación por campo y pantalla de confirmación.

Para ver cualquiera, abrí su `index.html` en el navegador.
