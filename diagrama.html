🤖 Chatbot WhatsApp + CRM

Diagrama de arquitectura, flujo y estructura del proyecto — Para práctica en equipo

📨 Flujo completo de un mensaje
1

Usuario envía mensaje por WhatsApp ENTRADA

El usuario escribe algo como "hola", "cuánto cuesta?" o "quiero comprar". Meta recibe el mensaje y lo envía al webhook de tu servidor.

2

Webhook recibe el evento POST /webhook

Express recibe el POST. El controller responde 200 OK inmediatamente a Meta para evitar reintentos. Luego procesa el mensaje de forma asíncrona.

3

Parseo del payload whatsapp.service.js

Se extraen del JSON de Meta: el número de teléfono (from), el texto del mensaje, el nombre del contacto y el ID del mensaje. Se ignoran status updates y mensajes no-texto.

4

Detección de intención bot/intents.js

El texto se normaliza (sin tildes, sin mayúsculas, sin caracteres especiales). Se compara contra keywords. Prioridad: frases multi-palabra → palabras sueltas → fallback desconocido.

5

¿Es un lead? → Guardar en Google Sheets sheets.service.js

Si la intención es precio o compra, se guarda automáticamente en el CRM: nombre, teléfono, mensaje, intención y fecha. Se usa la Google Sheets API con cuenta de servicio.

6

Respuesta automática por WhatsApp whatsapp.service.js

Se llama a POST https://graph.facebook.com/v19.0/{PHONE_NUMBER_ID}/messages con el token Bearer. El usuario recibe la respuesta en segundos.

Columna Campo Tipo Descripción Ejemplo

B Teléfono string Número completo con código de país, sin + 5491123456789
C Mensaje string Texto exacto que escribió el usuario cuanto cuesta el plan?

📡 Endpoints expuestos
GET /webhook Verificación del webhook por Meta. Devuelve hub.challenge si el token es válido.
POST /webhook Recibe eventos de WhatsApp. Responde 200 inmediato, procesa async. Detecta intención y responde.
GET /webhook/leads Retorna todos los leads del CRM en formato JSON. (Proteger con auth en producción)
GET /health Health check. Devuelve status, uptime y timestamp. Útil para monitoreo.
🚀 Setup para practicar en equipo
01

📦 Instalar dependencias

  • Clonar el repo o copiar la carpeta chatbot-whatsapp/
  • Ejecutar npm install en la raíz del proyecto
  • Verificar que exista la carpeta node_modules/
  • Copiar .env.example → .env
02

🔧 Configurar Meta / WhatsApp

  • Crear app en developers.facebook.com
  • Agregar producto: WhatsApp Business
  • Copiar Phone Number ID al .env
  • Generar token permanente → WHATSAPP_TOKEN
  • Definir tu propio VERIFY_TOKEN (cualquier string)
03

📊 Configurar Google Sheets

  • Google Cloud Console → crear proyecto
  • Activar Google Sheets API
  • Crear Cuenta de Servicio → descargar JSON
  • Del JSON: copiar client_email y private_key
  • Crear Spreadsheet → hoja llamada Leads
  • Compartir spreadsheet con el email de la cuenta de servicio
04

🌐 Exponer con ngrok + registrar webhook

  • Correr el server: npm run dev
  • En otra terminal: ngrok http 3000
  • Copiar la URL HTTPS de ngrok
  • En Meta: pegar https://xxx.ngrok.io/webhook
  • Ingresar el VERIFY_TOKEN del .env
  • Suscribir al evento: messages
